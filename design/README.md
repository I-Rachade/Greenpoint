# pointderecharge Design

- **Schrift:** Poppins (Titel, Buttons) und Inter (Texte, Zahlen), beide von Google Fonts.
- **Farben:** siehe `farbpalette.png`, als Werte in `tokens.json` und `tokens.css`.
- **Logo:** siehe `assets/logo/`.

## Regeln
- Auf Grün `#1DB954` immer dunkle Schrift `#0B3B2E`, nie Weiß (Kontrast nur 2,6 : 1).
- Weiße Schrift nur auf Grün dunkel `#12823B` oder Dunkelgrün `#0B3B2E`.
- Gelb `#FFC93C` immer mit Dunkelgrün kombinieren, vor allem für das Treueprogramm greenpoint.
- Statusfarben für Stationen: Grün = verfügbar, Orange = wenige Akkus, Rot = geschlossen, Blau = eigener Standort.
